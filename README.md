# Invictus Camp · Gestionale

Gestionale interno di Invictus Camp, il camp di terapia ricreativa per famiglie con persone con disabilità.
Lo usano tre tipi di account: amministrazione, famiglie e staff.

Stack: Nuxt 4, Nuxt UI 4, PostgreSQL con Drizzle ORM, email con Resend.
Comandi, struttura e regole del progetto sono in `CLAUDE.md`.
